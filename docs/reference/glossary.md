# Glossary

This glossary lists every technical term used on this site, in alphabetical order. Each term links to the page where it is first explained. Each page lists its new terms in a Terminology callout at the top. Terms already introduced in an earlier tutorial site aren't repeated in those callouts, but they are all listed here.

[A](#a) · [B](#b) · [C](#c) · [D](#d) · [E](#e) · [F](#f) · [I](#i) · [L](#l) · [M](#m) · [N](#n) · [O](#o) · [P](#p) · [Q](#q) · [R](#r) · [S](#s) · [T](#t) · [U](#u) · [V](#v) · [W](#w)

## A

- **algorithm** – step-by-step instructions for solving a problem, like a recipe. ([Lesson 7: Functions](../lessons/lesson_07.md))
- **and operator** – a Boolean operator that gives back `True` only if every value is `True`. ([Lesson 11: Boolean Logic](../lessons/lesson_11.md))
- **argument** – a value we send into a function or method when we call it. ([Lesson 7: Functions](../lessons/lesson_07.md))

## B

- **Boolean** – a data type that can only be `True` or `False`, called `bool` in Python. ([Lesson 8: User Input](../lessons/lesson_08.md))
- **Boolean operator** – an operator that works with `True` and `False` values and always gives back `True` or `False`. ([Lesson 11: Boolean Logic](../lessons/lesson_11.md))
- **branching** – letting a program choose between different paths depending on what is happening. ([Lesson 9: Branching](../lessons/lesson_09.md))
- **break** – a command that exits a loop straight away. ([Lesson 10: While Loops](../lessons/lesson_10.md))
- **breakpoint** – a place we mark in our code where the debugger pauses the program. ([Debugging with Thonny](../guides/debugging.md))
- **bug** – a mistake in a program that causes unexpected results. ([Debugging with Thonny](../guides/debugging.md))
- **built-in function** – a command that Python already knows, such as `print`, which Thonny colours purple. ([Lesson 1: Thonny Introduction](../lessons/lesson_01.md))

## C

- **call** – to run a function by using its name, after which the program comes back to where it was. ([Lesson 7: Functions](../lessons/lesson_07.md))
- **case sensitive** – treating capital and lowercase letters as different, so `age` and `Age` are two different names. ([Lesson 5: Variables](../lessons/lesson_05.md))
- **code block** – a group of lines indented by the same amount that belong together and run together. ([Lesson 3: Iteration](../lessons/lesson_03.md))
- **comment** – a line starting with `#` that Python ignores, written to help humans understand the code. ([Lesson 1: Thonny Introduction](../lessons/lesson_01.md))
- **commenting out** – adding `#` to the start of lines of code so Python ignores them, without deleting them. ([Lesson 6: Coordinates](../lessons/lesson_06.md))
- **comparison operator** – a symbol such as `==`, `!=`, `>` or `<` that compares two values and gives back `True` or `False`. ([Lesson 10: While Loops](../lessons/lesson_10.md))
- **condition** – a check that gives back either `True` or `False`. ([Lesson 9: Branching](../lessons/lesson_09.md))
- **condition-controlled loop** – a loop that runs until a condition changes, like a `while` loop. ([Lesson 10: While Loops](../lessons/lesson_10.md))
- **constant** – a variable whose value never changes while the program runs, written in capital letters in Python. ([Lesson 5: Variables](../lessons/lesson_05.md))
- **control structure** – code that changes the flow of a program, instead of just running from top to bottom. ([Lesson 3: Iteration](../lessons/lesson_03.md))
- **coordinates** – a pair of numbers, such as `(x, y)`, that gives a position on a screen or display. ([Lesson 6: Coordinates](../lessons/lesson_06.md))
- **count-controlled loop** – a loop that runs a set number of times, like a `for` loop. ([Lesson 10: While Loops](../lessons/lesson_10.md))

## D

- **data type** – the kind of value something is, such as a number or text, which tells Python what it can do with that value. ([Lesson 8: User Input](../lessons/lesson_08.md))
- **debugger** – a tool that runs our code one step at a time so we can see what it is doing and find mistakes. ([Lesson 3: Iteration](../lessons/lesson_03.md))
- **debugging** – the process of finding and fixing bugs in a program. ([Debugging with Thonny](../guides/debugging.md))
- **decision block** – a diamond in a flowchart that asks a question and splits the path based on the answer. ([Flowcharts](../guides/flowcharts.md))
- **define** – to create a function with `def`, giving it a name and a code block that Python remembers but doesn't run yet. ([Lesson 7: Functions](../lessons/lesson_07.md))
- **definite iteration** – a loop where we know how many times it will run, usually written as a `for` loop. ([Lesson 10: While Loops](../lessons/lesson_10.md))
- **DRY** – short for Don't Repeat Yourself, the principle that we shouldn't write the same code over and over again. ([Lesson 3: Iteration](../lessons/lesson_03.md))

## E

- **element** – one item in a list. ([Lesson 3: Iteration](../lessons/lesson_03.md))
- **elif** – short for else if, a part of an `if` statement that checks another condition when the conditions before it were `False`. ([Lesson 9: Branching](../lessons/lesson_09.md))
- **else** – the part of an `if` statement that runs when none of the conditions are `True`. ([Lesson 9: Branching](../lessons/lesson_09.md))

## F

- **floating point number** – a number with a decimal point, like `1.0` or `3.5`, called `float` in Python. ([Lesson 8: User Input](../lessons/lesson_08.md))
- **flow arrow** – an arrow in a flowchart that shows the path the program takes, in one direction only. ([Flowcharts](../guides/flowcharts.md))
- **flowchart** – a diagram that uses shapes and arrows to show each step in a program and how it moves from one step to the next. ([Lesson 3: Iteration](../lessons/lesson_03.md))
- **for loop** – a loop that repeats its code once for each item in a list or sequence. ([Lesson 3: Iteration](../lessons/lesson_03.md))
- **function** – a named block of code that we can run again and again whenever we need it. ([Lesson 7: Functions](../lessons/lesson_07.md))
- **function indicator** – a red dashed box drawn around the steps of a function in a flowchart. ([Flowcharts](../guides/flowcharts.md))

## I

- **if statement** – code that makes a decision by running its indented block only when its condition is `True`. ([Lesson 9: Branching](../lessons/lesson_09.md))
- **immutable** – describes something that can't be changed once it has been created. ([Lesson 6: Coordinates](../lessons/lesson_06.md))
- **import** – the command that tells Python to load a module so our program can use its commands. ([Lesson 2: Introducing Turtle](../lessons/lesson_02.md))
- **indefinite iteration** – a loop where we don't know how many times it will run, usually written as a `while` loop. ([Lesson 10: While Loops](../lessons/lesson_10.md))
- **indentation** – spaces at the start of a line (four in Python) that show which code belongs to a loop or other block. ([Lesson 3: Iteration](../lessons/lesson_03.md))
- **infinite loop** – a loop whose condition is always `True`, so it never stops on its own. ([Lesson 10: While Loops](../lessons/lesson_10.md))
- **input** – information that goes into a program, such as a key press, a mouse click or a sensor reading. ([Lesson 3: Iteration](../lessons/lesson_03.md))
- **input/output block** – a parallelogram in a flowchart, also called an IO block, that shows information moving between the real world and the program. ([Flowcharts](../guides/flowcharts.md))
- **integer** – a whole number written without a decimal point, like `1` or `25`, called `int` in Python. ([Lesson 8: User Input](../lessons/lesson_08.md))
- **interactive** – describes a program that lets the user give it information while it runs, instead of changing the code. ([Lesson 8: User Input](../lessons/lesson_08.md))
- **iteration** – repeating the same code again and again, often with a small change each time, also called looping. ([Lesson 3: Iteration](../lessons/lesson_03.md))

## L

- **list** – a collection of items stored in a set order inside `[` and `]`, with commas between them. ([Lesson 3: Iteration](../lessons/lesson_03.md))
- **local variable** – a variable that only exists inside the function that created it. ([Debugging with Thonny](../guides/debugging.md))
- **logic error** – a mistake where the code runs without crashing but doesn't do what we expected. ([Debugging with Thonny](../guides/debugging.md))
- **loop indicator** – a grey dashed box drawn around the steps in a flowchart that repeat in a loop. ([Flowcharts](../guides/flowcharts.md))
- **loop variable** – the variable in a `for` loop that stores the item or number the loop is currently using. ([Lesson 5: Variables](../lessons/lesson_05.md))

## M

- **magic number** – a number written straight into our code with no name to explain what it means. ([Lesson 5: Variables](../lessons/lesson_05.md))
- **maintainability** – how easy our code is for other people, or our future selves, to read, understand and change. ([Lesson 6: Coordinates](../lessons/lesson_06.md))
- **method** – a function that belongs to an object or value, written after a dot, such as `name.upper()`. ([Lesson 9: Branching](../lessons/lesson_09.md))
- **module** – a file of ready-made code that we can import into our program to use its commands. ([Lesson 2: Introducing Turtle](../lessons/lesson_02.md))
- **mouse input** – information a program gets from the mouse, such as where the user clicked. ([Lesson 12: Mouse Input](../lessons/lesson_12.md))

## N

- **naming convention** – an agreed habit for naming things that makes code easier to read, but doesn't cause an error if we break it. ([Lesson 5: Variables](../lessons/lesson_05.md))
- **not operator** – a Boolean operator that flips a value, so `not True` is `False` and `not False` is `True`. ([Lesson 11: Boolean Logic](../lessons/lesson_11.md))

## O

- **or operator** – a Boolean operator that gives back `True` if at least one value is `True`. ([Lesson 11: Boolean Logic](../lessons/lesson_11.md))
- **output** – information or actions that a program sends out, such as text on the screen, a sound or a motor moving. ([Lesson 3: Iteration](../lessons/lesson_03.md))

## P

- **parameter** – a variable name in a function definition that receives a value sent into the function. ([Lesson 7: Functions](../lessons/lesson_07.md))
- **parentheses** – the round brackets `(` and `)`, which must always come in matching pairs. ([Lesson 1: Thonny Introduction](../lessons/lesson_01.md))
- **pixel** – one of the tiny dots of light that make up a screen or display. ([Lesson 2: Introducing Turtle](../lessons/lesson_02.md))
- **process block** – a rectangle in a flowchart that shows a step where the code does something, like setting a variable or doing a calculation. ([Flowcharts](../guides/flowcharts.md))
- **Python** – the text-based programming language we use to write our programs. ([Lesson 1: Thonny Introduction](../lessons/lesson_01.md))

## Q

- **quadrant** – one of the four sections a window is split into by lines through its centre. ([Lesson 12: Mouse Input](../lessons/lesson_12.md))

## R

- **refactoring** – changing our code to make it better without changing what it does. ([Lesson 9: Branching](../lessons/lesson_09.md))
- **return** – to send a value back from a function to the code that called it, which also ends the function. ([Lesson 9: Branching](../lessons/lesson_09.md))
- **run-time error** – an error that happens while the program is running, which makes it crash. ([Debugging with Thonny](../guides/debugging.md))

## S

- **scalable** – describes code that still works well as the program gets bigger. ([Lesson 3: Iteration](../lessons/lesson_03.md))
- **screen** – the window that the turtle draws in. ([Lesson 2: Introducing Turtle](../lessons/lesson_02.md))
- **script** – a Python program saved as a text file. ([Lesson 1: Thonny Introduction](../lessons/lesson_01.md))
- **sequence** – code running one line after the other, from the top of the program to the bottom. ([Lesson 3: Iteration](../lessons/lesson_03.md))
- **Shell** – the panel in Thonny that shows what our program prints and any error messages. ([Lesson 1: Thonny Introduction](../lessons/lesson_01.md))
- **single point of truth** – keeping each value in one place, so changing it there changes it everywhere it is used. ([Lesson 5: Variables](../lessons/lesson_05.md))
- **snake case** – writing names in lowercase letters with `_` instead of spaces, like `side_length`. ([Lesson 5: Variables](../lessons/lesson_05.md))
- **stack** – the list of parts of the program that are currently running, such as the main program and any function it has called, which the debugger shows. ([Debugging with Thonny](../guides/debugging.md))
- **step into** – a debugger control that runs the next small piece of code and shows every step Python takes. ([Debugging with Thonny](../guides/debugging.md))
- **step out** – a debugger control that finishes the rest of the current piece of code and moves back out a level. ([Debugging with Thonny](../guides/debugging.md))
- **step over** – a debugger control that runs the highlighted code in one go without showing all the small steps. ([Debugging with Thonny](../guides/debugging.md))
- **string** – a group of characters, like letters, numbers or symbols, inside quotation marks. ([Lesson 1: Thonny Introduction](../lessons/lesson_01.md))
- **syntax error** – an error that happens when our code doesn't follow Python's rules. ([Lesson 1: Thonny Introduction](../lessons/lesson_01.md))
- **syntax highlighting** – colouring different parts of our code based on what they do, so it's easier to read and write correctly. ([Lesson 1: Thonny Introduction](../lessons/lesson_01.md))

## T

- **terminal block** – a rounded rectangle in a flowchart that shows where a program or function starts and ends. ([Flowcharts](../guides/flowcharts.md))
- **Thonny** – a program for writing, running and debugging Python code that is designed for beginners. ([Lesson 1: Thonny Introduction](../lessons/lesson_01.md))
- **tuple** – a group of values written in round brackets that works like a list but can't be changed. ([Lesson 6: Coordinates](../lessons/lesson_06.md))
- **turtle** – a small arrow on the screen that we can control and move around to draw. ([Lesson 2: Introducing Turtle](../lessons/lesson_02.md))

## U

- **user interface** – the screen of a program that we see and use, often shortened to UI. ([Lesson 1: Thonny Introduction](../lessons/lesson_01.md))

## V

- **variable** – a named place, like a labelled box, that stores a value our program can use and change. ([Lesson 5: Variables](../lessons/lesson_05.md))

## W

- **while loop** – a loop that keeps repeating its code while its condition is `True`. ([Lesson 10: While Loops](../lessons/lesson_10.md))
