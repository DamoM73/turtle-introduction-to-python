# Introduction for Teachers

I created this site for use with my secondary school students. It started with resources and examples from other teachers, so I also present it for other teachers to use.

This site supports my classroom practice by addressing two issues:

- the wide range of coding experience students bring to this introductory unit
- students who miss lessons and need to catch up

My pedagogical approach is:

- Students are given the website and invited to work at their own pace.
    - This lets students race ahead if they wish.
    - The [Extension Activities](extension.md) page links to more tutorials for students who finish early.
- I live code the content with the class.
    - This is the minimum progress I expect from students.
    - If they are behind what I'm doing in class, they need to catch up.
- If students fall behind, they can catch up using this site.

There are 12 lessons. Each lesson should take about one hour.

    If you find any errors in this work, please [raise an issue](https://github.com/DamoM73/turtle-introduction-to-python/issues) on GitHub so I can fix it.
